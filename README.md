# Git for DevOps / Ops Training

This repository contains materials and exercises for a basic Git training course, specifically designed for System Administrators, Operations, and DevOps profiles.

## Objectives

- Understand the internal workings of Git.
- Master the basic workflow (add, commit, push, pull).
- Learn how to manage branches and resolve conflicts.
- Use advanced tools for automation and productivity.
- Introduce the concept of GitOps.

## Course Structure

The course is divided into the following modules:

1.  **[01-introduction](./01-introduction)**: Why Git in Operations? (5 min)
2.  **[02-configuration](./02-configuration)**: Initial setup and productivity. (5 min)
3.  **[03-basic-workflow](./03-basic-workflow)**: The 3 stages of Git. (15 min)
4.  **[04-branching-merging](./04-branching-merging)**: Branch management. (25 min)
5.  **[05-remotes-collaboration](./05-remotes-collaboration)**: Team collaboration. (10 min)
6.  **[06-ops-power-tools](./06-ops-power-tools)**: Advanced commands (Stash, Cherry-pick, Rebase). (15 min)
7.  **[07-git-hooks](./07-git-hooks)**: Local automation (linting). (10 min)
8.  **[08-gitops-intro](./08-gitops-intro)**: The future of operations. (5 min)

## How to use this repository

There are two ways to follow this training:

### 1. Interactive Workshop (Recommended)
Run the interactive script to be guided through the exercises step-by-step:
```bash
./run-exercises.sh
```

### 2. Manual Study
Each directory contains a `README.md` file with theoretical concepts and a manual exercise guide.
